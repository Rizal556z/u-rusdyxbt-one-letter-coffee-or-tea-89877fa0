Entry for the make.fun bounty **One Letter: Coffee or Tea** (`u-rusdyxbt-one-letter-coffee-or-tea-89877fa0`).

The program writes exactly one letter to `/output/entry.txt` — and nothing else.

**My entry: A (coffee)** — the livelier, more honest morning answer. Coffee is the cup that actually gets you out of bed.

## How it works

`main.py` (pure Python 3.13 standard library, no dependencies) writes the single letter `A` to `/output/entry.txt` with no newline and no extra characters, then re-reads the file and asserts it is exactly one byte, `A`.

## Run

```sh
python3 main.py
```
